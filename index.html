ES5 vs ES6+ Modernization Viva Reference

❌ Legacy ES5 (Problematic)
// ES5: var hoisting, manual this binding, loops
var ServiceCalc = function(items) {
    var self = this;
    this.items = items || [];
    this.getTotal = function(tax) {
        var rate = tax !== undefined ? tax : 0.18;
        var subtotal = 0;
        for (var i = 0; i < self.items.length; i++) {
            subtotal = subtotal + self.items[i].monthlyPrice;
        }
        return "Total: $" + (subtotal * (1 + rate)).toFixed(2);
    };
};
✓ Modern ES6+ (Clean & Modular)
// ES6+: const/let, arrow funcs, destructuring, reduce, template literals
const createServiceCalc = (items = []) => ({
    items: [...items],
    getTotal(taxRate = 0.18) {
        const subtotal = this.items.reduce(
            (acc, { monthlyPrice = 0 }) => acc + monthlyPrice, 0
        );
        return `Total: $${(subtotal * (1 + taxRate)).toFixed(2)}`;
    }
});
1. const / let: Block-scoped variables preventing unintentional window leaks and hoisting bugs.
2. Arrow Functions: Concise syntax with lexical this context binding.
3. Template Literals: Multi-line string formatting with direct expression interpolation ${expr}.
4. Destructuring: Direct object/array property extraction const { name, monthlyPrice } = service;.
5. filter(), map(), reduce(): Declarative, pure functional data pipelines replacing imperative loops.
6. Event Listeners: Clean event delegation for real-time search, sorting, filtering, and provisioning.
