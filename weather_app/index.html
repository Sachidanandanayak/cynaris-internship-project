⚡ Under the Hood: Asynchronous Architecture & Security

This mini-project demonstrates modern frontend JavaScript practices: asynchronous flow control with native fetch(), clean error handling, and zero credential leakage.

fetch(url)

Non-blocking HTTP request returns a Promise resolving to the network response.

async / await

Synchronous-style syntax over native promises, eliminating callback nesting and unhandled rejections.

try / catch / finally

Defensive exception boundaries catching DNS, CORS, HTTP 4xx/5xx status codes, and JSON parsing faults.
